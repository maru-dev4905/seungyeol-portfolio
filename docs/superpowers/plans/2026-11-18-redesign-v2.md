## Global Constraints (상속 + 변경)

- 상속: 의존성 허용 목록(`lenis`, `gsap`, `@gsap/react`, 서체 파일), 토큰 규칙(색 리터럴 금지, 셰이더 팔레트는 토큰에서 읽기), 글래스 C 값, 작은 글자는 밝은 곡선 위 금지와 대비 4.5:1 실측, reduced-motion 규칙, SSR 텍스트 보존, 한글 `keep-all`, 커밋 금지, 한국어 "무엇을, 왜" 주석, Playwright는 scratchpad에서만.
- 변경 1: 팔레트 토큰 이름은 `--paint-ember/magenta/blue/navy/gold`가 아니라 **`--ramp-0`(가장 어두움)…`--ramp-4`(가장 밝은 빛)** 와 `--accent`이다. 기존 이름은 삭제하고 사용처를 모두 옮긴다.
- 변경 2: 테마는 `water`, `moss`, `dusk` 세 개. 토큰은 `:root`(기본 = `water`)와 `[data-theme="moss"]`, `[data-theme="dusk"]`에 정의한다. 모든 값은 `#rrggbb`. 제안값: water `#050b1f #0f2a7a #2a5bd7 #4fb3d9 #eaf6ff`, accent `#4fd1c5`; moss `#07120c #1f3d2a #3f6b3a #8fb36b #e9f6e3`, accent `#4fd1c5`; dusk `#0a0c28 #3a2f9a #b0388a #ff7a4a #fff0e6`, accent `#ffb347`. 눈으로 보고 대비 실측 후 조정 가능(조정 이유 보고).
- 변경 3: `Backdrop`은 **루트 레이아웃에서 한 번만** 렌더한다(페이지에서 렌더하지 않는다). 시그니처 `Backdrop({ intensity })`는 유지하되 `intensity`는 레이아웃에서 기본값만 쓰고, 페이지별 강도는 `ThemeSetter`의 `intensity` prop으로 바꾼다.
- 변경 4: 셰이더의 `uIntensity` gain(현재 `pow(uIntensity,1.7)`)은 올리지 않는다. 작은 글자 대비는 구조(패널·글래스·어두운 영역)로 지킨다.
- 추가: 챕터 사이 간격은 데스크톱 기준 1~1.5 뷰포트 높이, 제목은 `clamp`로 크게, 본문 폭 40em 이하.
- 추가: 글래스는 화면당 소수(상세: 정보 카드 하나와 알약 `ChapterNav`, 네비는 위쪽 알약). 총 3개를 넘기지 않는다.

### Task 1b: 모양 프리셋 (일렁이는 곡선의 형태·크기, 방문마다 jitter)

**Files:**
- Create: `apps/web/src/lib/shapes.ts`
- Modify: `apps/web/src/lib/theme.ts` (`setTheme`와 `subscribeTheme`에 shape 추가), `apps/web/src/components/theme/ThemeSetter.tsx`
- Modify: `apps/web/src/components/Backdrop/backdrop.frag.ts`, `BackdropCanvas.tsx`
- Modify: `apps/web/src/app/page.tsx`(메인 `rise`), 프로젝트 상세 페이지(`surface`)

**Interfaces:**
- Produces:
  - `shapes.ts`: `export type ShapeName = "rise" | "surface" | "ribbon" | "halo"`; `export type ShapeParams`(위치·크기·띠 폭·휘어짐·회전·원형↔띠 혼합·가장자리 글로우 위치 등 **모두 숫자**, 최대 `vec4` 3개 분량); `export const shapes: Record<ShapeName, ShapeParams>`; `export function jitterShape(params: ShapeParams, seed: number): ShapeParams` (seed에서 결정되는 순수 함수, 위치 ±, 회전 ±10° 안팎, 크기 ±10% 안팎, **프리셋의 안전 범위 안에서만**); `export const shapeNames: readonly ShapeName[]`.
  - `ThemeSetter(props: { theme: ThemeName; intensity?: "vivid" | "calm"; shape?: ShapeName }): null`; `setTheme(theme, opts?: { intensity?; shape? })`; `subscribeTheme`의 리스너에도 shape가 전달된다.
  - 셰이더: 하드코딩된 곡선 상수를 uniform(`uShapeA`, `uShapeB`, `uShapeC`)으로 바꾼다. 네 모양이 **하나의 같은 매개변수화**를 공유해서 프리셋 사이를 선형 보간해도 튀지 않고 흘러야 한다(원형 ↔ 띠는 혼합 계수로 연결, 부분적으로 화면 밖에 걸친 디스크로 가장자리 글로우 구도를 만든다).
  - `BackdropCanvas`: 방문(페이지 로드)마다 `Math.random()`으로 seed를 한 번 뽑아 `jitterShape`에 적용한다(하이드레이션 안전하도록 클라이언트에서만). 테마 보간과 같은 방식으로 약 1초 보간.
- 각 모양이 보여야 할 구도(레퍼런스 #9, #10, #8, Blur Light):
  - `rise`: 화면 가운데에 **큰 어두운 공간**, 위쪽을 따라 블루 빛 띠, 오른쪽 가장자리에 흰 빛이 터짐, 아래 왼쪽에 옅은 블루.
  - `surface`: 오른쪽 위 모서리의 **거대한 흰 빛**이 블루·시안으로 번져 내려오고 아래쪽에 어두운 반달.
  - `ribbon`: 화면을 가로지르는 S자 곡선 하나(지금 구도에 가까움).
  - `halo`: 화면의 약 절반을 차지하는 크고 둥근 빛 덩어리 하나, 가장자리가 부드러움.
  빛 면적은 이전보다 **눈에 띄게 크게**(가장 밝은 영역 포함 화면의 40~60%까지 허용) 하되 아래 대비 규칙을 지킨다.
- **완료 조건 (v2 Task 1 검증에서 발견)**: 현재 water는 최대 밝기가 약 92/255이고 가장 밝은 램프가 연한 시안 회색 띠로 보여 레퍼런스 #9, #10의 "얇고 선명하게 터지는 흰 빛 가장자리"가 없다. `rise`·`surface`에서는 **가장자리에 얇고 밝은 림(rim) 하이라이트**(흰색에 가까운 `--ramp-4`가 디스크 경계를 따라 가늘게 나타남)가 눈에 보여야 하고(밝은 픽셀 최대값이 이전보다 확연히 높아야 함, 수치 보고), vivid와 calm의 시각 차이도 눈에 보여야 한다. 단 림은 가늘어서 작은 글자 대비를 깨지 않는 범위여야 하고, 가늘다는 점이 곧 안전 근거이므로 측정으로 증명한다.
