# D-010 디자인: 핵심 화면만 Figma로

- 상태: 확정
- 날짜: 2026-11-17

> 메인, 프로젝트 상세, 섹션 컴포넌트만 Figma로 먼저 그리고, 관리자 화면은 코드로 바로 만든다.

## 고민한 선택지

| 안 | 방식 | 결과 |
| --- | --- | --- |
| A | 전부 Figma 먼저 | 관리자까지 그리는 건 시간 낭비 |
| **B** | **핵심 화면만 Figma** | **채택** |
| C | 코드로 바로 | 인터랙션 강한 화면은 만들면서 갈아엎게 됨 |

## 이유

- 관리자는 나만 보니 디자인에 시간을 쓸 필요가 적다.
- 메인처럼 인터랙션이 강한 화면은 먼저 그려야 만들면서 갈아엎지 않는다.
- Figma의 섹션 컴포넌트 목록은 zod 스키마의 `type` 목록(D-004, D-005)과 **짝을 맞춘다.**

## 남은 질문

메인 인터랙션과 색감 컨셉은 D-011에서 정했다. 세부(인터랙션 구체화, 팔레트)는 아직 남아 있다.
