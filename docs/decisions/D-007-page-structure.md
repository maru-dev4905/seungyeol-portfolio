# D-007 페이지 구성: 메인과 소개를 나눈다

- 상태: 확정
- 날짜: 2026-11-17

> 메인은 강한 인터랙션으로 "나는 이런 사람"을 보여주고 서브 페이지로 보내는 입구, 소개(`/about`)는 경력·스킬·이력 상세다.

## 배경

- 장기 목표가 Creative Technologist라 메인을 인터랙션 쇼케이스로 쓰고 싶다.
- FE 채용 담당자는 프로젝트 상세를 가장 오래 본다.

## 결정

| 구분 | 경로 |
| --- | --- |
| 방문자 | `/`, `/projects`, `/projects/[slug]`, `/about` |
| 관리자 | `/admin/login`, `/admin/projects`, `/admin/projects/[id]`, `/admin/codes` |

페이지별 렌더링 방식은 D-008.

## 면접 포인트

- 인터랙션이 무거워도 **첫 화면 로딩(LCP)을 지킨 방법**
- `prefers-reduced-motion` 대응
- 인터랙션을 건너뛰고 바로 프로젝트로 가는 길
