# D-011 디자인 컨셉: 그레이니 그라데이션 + 리퀴드 글래스

- 상태: 확정 (인터랙션 구체화·팔레트 미정)
- 날짜: 2026-11-17

> 색이 번지며 흐르는 그레이니 그라데이션을 배경으로 두고, 그 위에 리퀴드 글래스 UI를 올린다.
> "번지는 물감(배경) 위를 흐르는 물방울(유리)."

## 배경

나를 설명하는 말은 **"동화 같은 삶"**, **"어디든 적응해 흐르는 물"**이다.
후보는 리퀴드 글래스, 그레이니 그라데이션, 레트로 픽셀, 스위스 스타일 네 가지였다.

## 이유

- 유리는 뒤에 비칠 게 있어야 보인다. 단색 배경 위의 글래스는 거의 티가 안 나고, 움직이는 그라데이션이 있어야 굴절과 블러가 살아난다.
- 두 스타일 모두 물과 동화의 느낌에 닿는다.
- 그레인(노이즈)은 그라데이션의 계단 현상(밴딩)도 가려준다.

## 주의할 점

| 항목 | 대응 |
| --- | --- |
| 성능 | 움직이는 그라데이션 + `backdrop-filter` + 노이즈는 GPU를 많이 쓴다. 배경은 캔버스/WebGL 셰이더 하나로 그리고, 글래스 요소 수를 제한하고, 모바일에서는 효과를 줄인다 |
| 가독성 | 화려한 배경 위 유리 속 글자는 대비가 약하다. 메인은 화려하게, 상세·소개는 배경을 낮추고 패널을 더 불투명하게 해서 글이 먼저 읽히게 한다 |
| 접근성 | `prefers-reduced-motion`이면 배경을 멈춘다. 유리 위 글자 대비를 확인한다 |

## 프로젝트 상세의 기본 섹션 순서

관리자에서 새 프로젝트를 만들 때 미리 깔아둔다.
문제 발견 → 설계 결정 → 구현 → 트러블슈팅 → 임팩트(숫자) → 배운 점.

## 면접 포인트

무거운 시각 효과를 넣으면서 **성능과 접근성을 어떻게 지켰나.**
실제 측정값(LCP, FPS)을 남기면 성과 섹션 재료가 된다.
